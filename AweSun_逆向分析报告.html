4.4 剪贴板同步协议

基于自定义二进制协议 _ORAY_MSG_HEAD，消息类型包括 ID_CB_SEND_TYPE_ORAY（类型通告）、 ID_CB_REQUEST_DATA_ORAY（数据请求）、ID_CB_SEND_DATA_ORAY（数据响应）。 支持文本、位图、HTML、RTF、文件列表；文件传输支持拖拽和剪贴板双通道，可分别开关。

5.3 关键技术决策

为什么用 PowerShell
目标机器仅有 .NET Runtime，无 Python/Node/SDK。PowerShell 是 Windows 原生组件，可直接调用 .NET Framework 全部类库，无需安装任何依赖。
为什么用 JPEG 而非 H.264
PowerShell 无法直接调用硬件编码器。JPEG 编码可通过 System.Drawing.Imaging 完成，虽带宽占用高，但实现简单、延迟低、兼容性好，适合 MVP 验证。
为什么用 WebSocket
浏览器原生支持，跨平台无需插件；支持二进制帧传输 JPEG；JSON 控制消息易于调试；天然支持 NAT 穿透（配合内网穿透工具）。

六、AweSun 可借鉴的设计模式

插件化架构
oray::plugin::* 命名空间下每个功能都是独立插件，通过 router/handler 模式解耦。MiniSun 虽未完全插件化，但保留了 agent 与 controller 的清晰分层。
多通道传输
主通道走 TCP 保证可靠性，P2P 通道走 UDP 降低延迟，辅助通道处理剪贴板/文件。MiniSun 使用单一 WebSocket，但消息分类型设计保留了扩展性。
输入桌面切换
OpenInputDesktop + SetThreadDesktop 是处理 Windows UAC/锁屏远程输入的关键。MiniSun 的 agent.ps1 同样实现了这一机制。
驱动级增强
虚拟显示器、镜像捕获、虚拟 HID 都是驱动级方案，性能远超用户态 API。这是商业远控软件的技术壁垒，个人版难以复刻，但可通过 Windows.Graphics.Capture (Win10+) 接近。
