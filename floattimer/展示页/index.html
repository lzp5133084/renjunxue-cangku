CORE FEATURES

三种模式，一个悬浮球就够了

悬浮于任何程序之上，不打断你的工作流——文档、会议、游戏画面照常操作，时间余光一扫即见

⏱
正计时 / 秒表
一键开跑，毫秒级精度。支持计次打点，自动记录每段间隔，适合运动训练、演讲排练、任务耗时统计。
⏳
倒计时
时分秒自由设定，内置 1/5/10/25分钟、1小时 快捷档位。进度环实时可见，结束声音+通知双提醒。
🍅
番茄钟
工作25分钟 → 休息5分钟，4轮自动进入长休息。阶段自动切换，参数全部可自定义。
HOW IT WORKS

四步上手，10秒学会

左右切换查看完整操作流程

STEP 01
选择模式
打开主面板，顶部一键切换：正计时 / 倒计时 / 番茄钟。毛玻璃面板支持拖动摆放、一键收起。
STEP 02
设定时长
时/分/秒自由输入，或点快捷按钮（1分钟～1小时）。番茄钟的工作、短休、长休时长也能自定义。
STEP 03
悬浮球随身走
主面板收起后缩成一颗悬浮球：按住拖到任意位置，松手自动吸附屏幕边缘，双击展开面板，右键唤出快捷菜单。
STEP 04
开始专注
点击「开始」，悬浮球亮起绿色光环。最小化后系统托盘图标实时显示剩余分钟数，结束自动声音提醒。
USE SCENARIOS

悬浮在最上层，操作互不打扰

办公 · 会议 · 游戏 · 厨房——它钉在屏幕最上层，你只管做手头的事

场景 01
💼 办公改方案
改方案正到关键处，悬浮球钉在PPT右上角，抬头即见剩余时间。不切窗口、不抢焦点，思路一秒都不打断。
场景 02
🎓 网课 / 会议
共享屏幕讲方案，悬浮时间只有你自己看得见。发言节奏心里有数，该收尾时从容收尾，不再超时被打断。
场景 03
🎮 游戏 / 直播
全屏游戏激战正酣，悬浮球半透明挂在画面一角。煮面、休息提醒一个不漏——切出游戏看时间？不存在的。
场景 04
🍳 厨房烹饪
照着平板上的菜谱一步步操作，悬浮倒计时浮在菜谱页面上方。手上有油也不慌，不用碰屏幕切应用。
GET STARTED

现在就开始，让每一秒都算数

三种方式，随你挑

  • 电脑端：进入「电脑端」文件夹，运行 main.py，悬浮球即刻出现在桌面右下角
  • 网页端：浏览器打开「网页端/index.html」，手机电脑通吃，免安装
  • 后台管理：运行 admin_db.py，管理员账户 18180309010 统一管理
💡 为什么选择悬浮计时器？ 普通计时器要切窗口才能看时间，来回一切换思路就断了；悬浮计时器让时间一直在你视野里——余光一扫就知道还剩多久，手上的操作一刻不停。
