【本次新增功能】
一、剪贴板同步（主控端「📋 剪贴板」面板）
  - agent 端：clip_get → Get-Clipboard -Raw；clip_set →
    Set-Clipboard；回复 clip_text / clip_ok
  - controller 端：获取远端 / 复制到本机 / 发送到远端 三键
二、文件传输（主控端「📁 文件」侧面板）
  - 目录浏览 file_list（目录排序在前，支持上一级、手动输路径）
  - 下载 file_get → file_begin/chunk/end（256KB 分片 base64）
  - 上传 file_put_begin/chunk/end（192KB 分片，落盘当前目录）
  - 单文件上限 500MB；传输期间推流帧率短暂下降属正常
三、体验与修复
  - server.ps1 改 $PSScriptRoot 相对路径 + MIME 表 + 启动横幅
  - 面板改为从工具栏下方开始，不再遮挡顶部按钮
  - 文件列表改事件委托绑定（修复点击目录无反应）
  - toast 提示加 pointer-events:none（透明态不再拦截点击）
  - agent 支持「新连接优先」：检测到新主控端排队自动让位，
    解决旧标签页占线导致新连接卡"加载中"的问题

【调试过程中踩的坑（记录供以后参考）】
1. PowerShell 5.1 解析无 BOM 的 UTF-8 脚本会按 GBK 乱码 →
   含中文的 .ps1 必须带 BOM
2. 集合类型与 $null 比较必须写 $null -ne $list（$list -ne $null
   会对元素做过滤，空 List 求值为 false，导致 AddRange 被跳过、
   上传落盘 0 字节）
3. agent 单连接阻塞 accept：旧 WebSocket 会话不断开时新连接
   永远排队 → 推流循环加 listener.Pending() 检查让位

【当前限制（如实说明）】
- 剪贴板仅同步纯文本（AweSun 支持位图/HTML/RTF/文件）
- 文件传输为手动浏览式，非拖拽
- 无鉴权与加密（ws://），仅限可信局域网使用
- 虚拟显示器、USB 重定向、服务驻留仍未实现（需驱动/服务，
  属驱动级增强，个人版 MVP 暂不做）
